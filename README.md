# Vellum

Vellum is a lightweight personal expense ledger for recording and reviewing everyday transactions.

The app is browser-local and USD-only. Entries stay in the current browser's local storage; there is no account or cloud sync.

## Run locally

```sh
pnpm install
pnpm dev
```

Run the project checks with `pnpm verify`.

## Use the ledger

Open Ledger to review transactions and add or edit an entry. Use navigation to move between the ledger and the other app sections. Choose a theme from the appearance control. Use Reset only when you want to clear the ledger stored in this browser.
